# 课程知识映射

本项目不是单一算法作业，而是从问题分析、数据建模、算法实验到软件平台交付的综合实践。

| 课程知识 | 项目中的具体应用 | 形成的能力 |
| --- | --- | --- |
| Python 程序设计 | 使用 Pandas、NumPy、Scikit-learn、XGBoost 完成数据读取、清洗、训练和评估 | 面向数据问题编程 |
| 机器学习 / 数据挖掘 | 将交易记录建模为二分类问题，使用梯度提升树识别可疑交易 | 特征、模型、指标和泛化意识 |
| 数据库原理 | 设计用户、NFT、活动、交易和关系表，提供 SQL 初始化脚本 | 业务实体建模与数据持久化 |
| 软件工程 | 采用模块化后端、REST 接口、权限控制和前后端分离架构 | 从原型走向可维护系统 |
| Web 应用开发 | Vue + Element UI 实现风险列表、用户管理和链条展示页面 | 交互式业务系统开发 |
| 信息安全与隐私计算 | 以联邦学习避免原始数据跨平台集中，结合身份、权限和日志机制 | 隐私保护与安全治理意识 |
| 区块链 / NFT | 围绕铸造、上市、交易、用户和交易链条设计风险评估维度 | 将技术知识映射到新兴业务 |
| 创新创业与项目管理 | 使用精益画布、商业计划书和安全评估方案梳理客户、价值和落地路径 | 需求分析、产品表达和成果汇报 |

## 教学建议

可将项目拆成四个递进任务：

1. 从 CSV 交易数据出发，完成清洗、探索和基线模型；
2. 用 XGBoost 完成训练、交叉验证、准确率/AUC 评估和特征重要性分析；
3. 将单机训练改造成多参与方的联邦训练流程，讨论“数据不出域”的边界；
4. 通过 API、数据库和前端页面把模型结果转化为平台功能。
